Mutation Landscape Explorer

Analysis

Cohort-level mutation analysis of TCGA-LAML (acute myeloid leukemia): an oncoplot of the most frequently mutated genes and a breakdown of mutation types across 193 tumor samples.

python · pandas · matplotlib · MAF/TCGA data

Survival Analysis Dashboard

Statistics

Kaplan-Meier survival curves and log-rank tests comparing patient outcomes by mutation status across four AML driver genes in TCGA-LAML.

python · lifelines · pandas · TCGA-LAML clinical data

Driver Mutation Classifier

Machine Learning

A Random Forest classifier that predicts whether a mutation sits in a known cancer driver gene, using only mutation-level features (VAF, hotspot recurrence, variant type) — not gene identity — to avoid trivially memorizing the label.

python · scikit-learn · pandas · TCGA-LAML MAF data

Variant Annotation Pipeline

Pipeline

A from-scratch annotator that maps raw variant positions to genes and predicts variant type, validated against the professionally annotated MAF as ground truth — including a real bug found and fixed along the way.

python · pandas · scikit-learn · TCGA-LAML MAF data
