# Mutation Landscape Explorer

Cohort-level somatic mutation analysis of Acute Myeloid Leukemia (AML), reproducing a
standard cancer genomics visualization (the oncoplot) from a public TCGA dataset.

## Overview

Given a cohort of sequenced tumor samples, this analysis answers the first question of any
cancer genomics study: **which genes are mutated, in how many patients, and what kind of
mutations are they?** It computes cohort-level summary statistics, a mutation-type breakdown,
and builds an oncoplot of the most frequently mutated genes — the standard visualization used
throughout the cancer genomics literature (e.g. the original TCGA pan-cancer studies) to
communicate this at a glance.

## Dataset

| **Cohort** | TCGA-LAML — Acute Myeloid Leukemia, The Cancer Genome Atlas |
| **File** | `tcga_laml.maf` (Mutation Annotation Format) |
| **Source** | Bundled as example data with the [`maftools`](https://github.com/PoisonAlien/maftools) R/Bioconductor package |
| **Samples** | 193 patients |
| **Total somatic mutations** | 2,207 |
| **Unique genes mutated** | 1,611 |
| **Reference genome build** | GRCh37 / hg19 (NCBI build 37) |

This is the same de-identified, publicly released cohort as the original TCGA AML study
(Cancer Genome Atlas Research Network, *N Engl J Med* 2013), redistributed as a standard
example dataset in the bioinformatics community. No patient-identifying information is
present in the file (TCGA barcodes only).

## Methods

1. Load the MAF file and compute cohort-level summary statistics (sample count, mutation
   count, mutations per sample).
2. Tabulate the frequency of each `Variant_Classification` (missense, nonsense, frameshift,
   splice site, silent, etc.).
3. Rank genes by **number of unique samples** carrying a mutation (not raw mutation count —
   this avoids over-weighting genes with several mutations in a single patient).
4. For the top 20 genes, build a gene × sample matrix; where a sample carries more than one
   mutation type in the same gene, the cell is labeled `Multi_Hit`.
5. Render the matrix as an oncoplot (matplotlib), colored by mutation type, with a side panel
   showing percent of cohort mutated per gene.

## Results

- Average mutation burden: **11.44 mutations/sample**
- Mutation type composition: missense (60.8%), silent (20.3%), nonsense (4.7%), splice site
  (4.2%), frameshift insertion (4.1%), and smaller fractions of other classes
- Top 3 mutated genes by percent of cohort: **FLT3 (26.9%)**, **DNMT3A (24.9%)**,
  **NPM1 (17.1%)**

**Validation:** FLT3, DNMT3A, and NPM1 are the three most well-established AML driver genes
in the literature, in approximately the expected order of frequency. This was not
hard-coded — it is the direct output of the aggregation pipeline, and serves as independent
confirmation that the analysis is implemented correctly.

## Limitations & Future Work

- Gene ranking uses raw mutation frequency, not statistical significance of recurrence
  (e.g. MutSigCV-style background mutation rate correction) — a gene can appear "frequently
  mutated" here without formal evidence it is under positive selection.
- No filtering for known sequencing artifacts or low-VAF (possible subclonal/false-positive)
  calls.
- Planned extension: cross-reference top genes against a curated driver gene panel (see the
  companion [Driver Mutation Classifier](../driver-classifier/) project) to distinguish likely
  drivers from recurrently-mutated passengers.
