# Survival Analysis Dashboard

Kaplan-Meier survival analysis testing whether mutation status in specific driver genes is
associated with overall survival in Acute Myeloid Leukemia (AML).

## Overview

Knowing a gene is frequently mutated (see the companion
[Mutation Landscape Explorer](../mutation-landscape/)) does not establish that it matters
clinically. This analysis asks the natural follow-up question: **do patients carrying a
mutation in a given gene survive differently than patients without one?** For each of four
genes, patients are split into mutant vs. wild-type groups, a Kaplan-Meier survival curve is
fit for each group, and a log-rank test evaluates whether the two curves differ more than
expected by chance.

## Dataset

| **Cohort** | TCGA-LAML — Acute Myeloid Leukemia, The Cancer Genome Atlas (same cohort as the Mutation Landscape project) |
| **Mutation data** | `tcga_laml.maf`, from [`maftools`](https://github.com/PoisonAlien/maftools) |
| **Clinical data** | `tcga_laml_annot.tsv`, also distributed with `maftools` |
| **Clinical fields used** | `days_to_last_followup`, `Overall_Survival_Status` (1 = death recorded, 0 = censored/alive at last contact) |
| **Cohort with valid follow-up data** | 188 of 200 patients (12 excluded — see Data Quality below) |
| **Events observed** | 122 deaths, 66 censored |
| **Genes tested** | FLT3, DNMT3A, NPM1, TP53 (the four most frequently mutated genes per the Mutation Landscape analysis) |

## Data Quality Note

The raw clinical file uses the literal string `-Inf` as a placeholder for "no valid
follow-up time available," which is silently parsed by pandas as a real floating-point
negative infinity rather than a missing value. This was detected and handled explicitly:
all non-finite values are converted to `NaN` and the corresponding 12 patients (of 200) are
excluded from the survival analysis, since no valid duration exists for them. Left
unhandled, this would have produced incorrect survival curves without any error being
raised.

## Methods

1. Load MAF and clinical data; clean the `-Inf` placeholder as described above.
2. For each gene of interest, tag each patient as mutant (≥1 mutation in that gene per the
   MAF) or wild-type.
3. Fit a Kaplan-Meier estimator (`lifelines.KaplanMeierFitter`) separately for each group.
4. Run a log-rank test (`lifelines.statistics.logrank_test`) to obtain a p-value for the
   difference between the two survival curves.
5. Repeat for all four genes and summarize in a 2×2 panel figure.

## Results

| Gene | n mutant | n wild-type | log-rank p-value |
|---|---|---|---|
| TP53 | 14 | 174 | < 0.0001 |
| DNMT3A | 45 | 143 | 0.0011 |
| FLT3 | 49 | 139 | 0.1412 |
| NPM1 | 33 | 155 | 0.8083 |

**TP53**-mutant patients show a sharp, highly significant survival disadvantage, consistent
with TP53 mutations being one of the strongest known adverse prognostic markers in AML.
**DNMT3A** mutation is also associated with significantly worse survival. **FLT3** and
**NPM1** do not reach significance as simple binary splits in this cohort — a genuine and
informative negative result, discussed below rather than omitted.

## Limitations & Future Work

- **FLT3**: this analysis groups all FLT3 mutation types together. The published literature
  is specific that it is the **FLT3-ITD** subtype (internal tandem duplication) that carries
  prognostic significance, not FLT3 mutations broadly — this is the most likely explanation
  for the non-significant result here, and a natural next step is separating ITD from other
  FLT3 mutation types before re-testing.
- **NPM1**: NPM1's prognostic effect in the literature is known to be conditional on FLT3
  co-mutation status (NPM1-mutant/FLT3-wild-type patients have a notably better prognosis).
  A simple two-group split by NPM1 status alone does not capture this interaction.
- No multivariate adjustment (e.g. Cox proportional hazards regression) for age, FAB
  subtype, or co-occurring mutations — each gene here is tested independently.
- Planned extension: multivariate Cox regression including all four genes jointly, plus
  age and FAB classification as covariates.
